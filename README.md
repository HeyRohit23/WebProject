# 📸 Image Gallery App

A responsive and dynamic Image Gallery web application built using React.js. This project fetches images from a REST API and displays them in a clean, user-friendly interface with pagination and smooth loading experience.

## 🚀 Features
- Fetch images from API using Axios
- Pagination for browsing images
- Responsive design for all devices
- Reusable React components
- Smooth loading states for better UX

## 🛠️ Tech Stack
- React.js
- JavaScript (ES6+)
- Tailwind CSS
- Axios

## 📂 Project Functionality
- Displays images dynamically from API
- Allows users to navigate between pages
- Optimized UI for performance and responsiveness

## 🎯 Learning Outcomes
- Improved understanding of React Hooks (useState, useEffect)
- API integration using Axios
- Component-based architecture
- Responsive UI design
